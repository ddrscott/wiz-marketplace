How to use

  1. Open your dev app (e.g. http://localhost:8787/) in a new tab.
  2. Click the app-feedback-now bookmark. A floating feedback button appears bottom-right.
  3. Highlight text or click select element to anchor a comment. Type your note, then submit the batch.
  4. Claude reads inbox.jsonl, edits the source files of your app, and writes a change record to history.json. The page auto-reloads with a walkthrough.

Pages with strict Content-Security-Policy

If clicking the bookmarklet does nothing and the browser console shows a CSP error, your dev server is blocking cross-origin scripts. For Cloudflare Workers / Astro / Hono in dev mode this is rare, but if it happens, the cleanest fix is to relax the dev-only CSP to allow {{ENDPOINT}}.

When you're done

You don't usually need to do anything — the sidecar auto-shuts-down when Claude Code exits or after 10 minutes of no client traffic. To stop it now: lsof -ti:{{PORT}} | xargs kill, or say "stop app-feedback-now" in your Claude Code session.
